# پرداخت من

صفحه‌ی پرداخت شخصی: ادمین مبلغ وارد می‌کنه، لینک پرداخت می‌سازه و برای پرداخت‌کننده می‌فرسته.
درگاه زرین‌پاله و هر دو مسیرش از [korsi-pay](https://hamgit.ir/pishrun/products/korsi/korsi-pay) روی `checkout.vpsbaz.ir` رد می‌شه
(ورود به درگاه از `/start/<authority>` و بازگشت از `/<host>/cb`)، چون زرین‌پال فقط دامنه‌ی ثبت‌شده‌ی مرچنت رو قبول می‌کنه.

- `/admin` — پنل (ورود با نام کاربری و رمز، یا خودکار داخل مینی‌اپ تلگرام)
- `/p/<code>` — صفحه‌ی پرداخت؛ مبلغ ثابت یا آزاد، یک‌بار یا چندبار مصرف
- `/cb` — بازگشت از درگاه، تأیید پرداخت و رسید
- ربات تلگرام — ساخت لینک با فرستادن مبلغ (`250000 طراحی لوگو`)، لیست لینک‌ها و پرداخت‌ها، توقف/حذف، گزارش، و پیام برای هر پرداخت موفق. دکمه‌ی منوی ربات پنل رو به‌صورت مینی‌اپ باز می‌کنه.

بدون وابستگی؛ Node ۲۲.۱۳+ با SQLite داخلی.

```bash
cp .env.example .env   # بدون ZARINPAL_MERCHANT، درگاه آزمایشی داخلی فعاله
node --env-file=.env --disable-warning=ExperimentalWarning src/server.js
```

روی Coolify با Dockerfile بالا میاد؛ پوشه‌ی `/data` (دیتابیس) باید volume دائمی باشه.
میزبان این سرویس باید در `ALLOWED_HOSTS` سرویس korsi-pay باشه.
